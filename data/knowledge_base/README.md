# Knowledge Base

放在這個目錄的 `.txt` 和 `.md` 檔案，會在每次 `/brief`（daily_brief）執行時**原文整篇**讀進 prompt，直接當背景知識給 LLM 參考——不做 chunk、不做 embedding、不做向量搜尋。內容量小（個人筆記等級）完全塞得進 context，不需要這些機制。

> 此目錄的 `.txt` 和 `.md` 已加入 `.gitignore`，不會被 commit。

---

## 如何新增知識

1. 把檔案放進這個目錄（`.txt` 或 `.md` 皆可）
2. 不用額外執行任何指令——下次 `/brief` 或排程報告執行時就會自動讀到最新內容

---

## 適合放什麼

- 技術分析筆記（均線策略、KD 操作方式、量價關係）
- 產業研究摘要
- 個人交易規則與停損邏輯
- 任何希望 agent 能引用的背景知識

保持每份文件精簡（個人筆記等級），因為現在是整篇塞進 prompt，不是挑相關段落——文件量一大會直接推高每次分析的 token 成本。
